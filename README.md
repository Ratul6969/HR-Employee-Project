# HR Employee Attendance Insights 📅

A Power BI project that visualizes and analyzes attendance data of employees over April–June 2022 to uncover key patterns.

## 🎯 Goals
- Identify presence percentage, WFH trends, and sick leave distribution
- Detect most/least attended days
- Assist HR in understanding employee behavior

## 📊 Tools
- Microsoft Power BI
- Excel (Data cleaning)

## 📌 Key Insights
- Mondays and Tuesdays had the highest presence
- Work-from-home was most common in May
- Sick leaves peaked mid-month

## 📂 Files
- Power BI dashboard (`.pbix`)
- Processed Excel data
